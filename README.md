# 居合 IAIDO.SEC

**Путь клинка в мире кода.** Додзё цифровой безопасности: философия бусидо, честные рабочие инструменты для ИБ и арсенал профессионала — всё в одной статической странице без сборки и зависимостей.

## Особенности

- **七徳 Бусидо цифрового ронина** — семь добродетелей самурая, переведённые на язык информационной безопасности.
- **道場 Додзё инструментов** — восемь честных, полностью рабочих инструментов ИБ (см. ниже).
- **武器庫 Арсенал** — каталог реальных профессиональных инструментов индустрии со ссылками на официальные сайты.
- **誓約 Клятва этичного клинка** — кодекс легального и этичного использования.
- Ноль зависимостей: чистые HTML/CSS/JS, ни одного `npm install`, ни одной сборки. Открывается как обычный файл или деплоится на GitHub Pages за секунды.

## Инструменты додзё

Все инструменты работают **полностью в браузере**. Ничего не отправляется на сервер, кроме двух явно обозначенных случаев, использующих публичные API с CORS:

| # | Инструмент | Как работает |
|---|---|---|
| 一 生成 | Генератор паролей | `crypto.getRandomValues` + rejection sampling (без смещения по модулю) |
| 二 測定 | Анализ прочности пароля | Энтропия Шеннона + штрафы за шаблоны/словарные пароли, локально |
| 三 封印 | Hash Forge | SHA-1/256/384/512 через `crypto.subtle`, для текста и файлов (проверка целостности) |
| 四 検問 | Проверка утечек | k-anonymity модель Have I Been Pwned — на сервер уходят первые 5 символов SHA-1, не пароль |
| 五 暗号 | Клинок шифров | Цезарь / Виженер / XOR (учебные) + настоящий AES-256-GCM (PBKDF2, Web Crypto) |
| 六 変換 | Конвертер | Base64 / Hex / URL, UTF-8-безопасно |
| 七 解析 | JWT Инспектор | Разбор header/payload локально; честно предупреждает, что подпись не проверяется |
| 八 斥候 | Разведка (Recon) | Показывает, что о вас пассивно знает браузер (User-Agent, IP через api.ipify.org и т.д.) |

## Запуск локально

Статика — открывайте как угодно:

```bash
python3 -m http.server 8080
# или
npx serve .
```

## Деплой на GitHub Pages

1. **Settings → Pages → Source → GitHub Actions** — ничего дополнительно настраивать не нужно, workflow `.github/workflows/pages.yml` уже всё делает при пуше в `main`.
2. Либо классический способ: **Settings → Pages → Source → Deploy from a branch**, выбрать `main` / `/ (root)`.
3. Сайт полностью статический — сборка не требуется.

## Структура

```
index.html          — разметка и контент
css/style.css        — дизайн-система (тушь, васи, сталь)
js/main.js            — навигация, скролл-эффекты, UI
js/tools.js            — логика всех восьми инструментов
assets/img/           — изображения (фон героя)
.github/workflows/pages.yml — автодеплой на GitHub Pages
```
