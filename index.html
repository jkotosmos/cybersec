道場додзё инструментов

Восемь техник ремесла

Всё честно: никакого фейкового «AI-scan», никаких выдуманных чисел. Пароли и тексты не покидают браузер, если это не явно нужно для запроса к внешнему сервису — об этом всегда сказано отдельно.

生成 — Генератор паролей

Использует crypto.getRandomValues с отбраковкой смещения (rejection sampling) — честная криптографическая случайность, а не Math.random().

нажмите «сгенерировать»

測定 — Анализ прочности пароля

Расчёт по формуле Шеннона (энтропия = длина × log₂(размер алфавита)) со штрафами за словарные и клавиатурные шаблоны. Пароль нигде не сохраняется и никуда не отправляется.

—

    封印 — Hash Forge

    SHA-1 / SHA-256 / SHA-384 / SHA-512 через crypto.subtle. MD5 намеренно не реализован — он криптографически сломан. Годится для проверки целостности файлов.

    検問 — Проверка утечек пароля

    Модель k-anonymity: браузер считает SHA-1 пароля локально и отправляет в Have I Been Pwned только первые 5 символов хеша. Полный пароль и полный хеш никогда не покидают устройство. Требуется сеть.

    暗号 — Клинок шифров

    Цезарь / Виженер / XOR — учебные шифры прошлого, показывают принципы, но не защищают ничего реального. AES-256-GCM — настоящее современное шифрование (PBKDF2 + AES-GCM через Web Crypto), пригодное для короткого секрета.

    変換 — Конвертер Base64 / Hex / URL

    UTF-8-безопасное кодирование/декодирование прямо в браузере.

    解析 — JWT Инспектор

    Подпись НЕ проверяется — это просмотр содержимого токена, а не подтверждение его подлинности. Разбор происходит полностью локально.
